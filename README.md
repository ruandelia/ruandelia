### 👨‍💻 Sobre Mim

Sou um Desenvolvedor em constante evolução. Minha jornada começou com uma base sólida em **Engenharia de Software Web** utilizando **PHP e MySQL**, onde aprendi na prática a construir sistemas seguros (Auth, ACL, CRUD).

Atualmente, estou migrando minha stack para o ecossistema moderno de **JavaScript/TypeScript**, focando em performance e escalabilidade.

- 🔭 **Trabalhando atualmente em:** Projetos acadêmicos e pessoais de alto nível.
- 🌱 **Estudando:** Arquitetura de Software com **Nest.js** e Interfaces Reativas com **React/Next.js**.
- ⚡ **Diferencial:** Uno a lógica de backend (segurança/banco de dados) com a agilidade do frontend moderno.
